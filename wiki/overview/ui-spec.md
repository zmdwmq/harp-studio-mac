# UI 设计规格与用户偏好 (UI Spec)

> 基于 2026-11-26 用户访谈确认的产品与界面定调。

## 1. 视觉风格
- **暗色专业工作站风**：深灰/炭黑底色（`#0f1117` / `#181b24`）+ 霓虹荧光点缀（吹气蓝 `#38bdf8`、吸气琥珀橙 `#fb923c`、录音红 `#f43f5e`、准音绿 `#34d399`），护眼且突出波形、电平表与口琴孔位。

## 2. 默认硬件工作流适配
- **默认硬件**：桌面声卡 + 麦克风（如 **Yamaha AG06mk2**，声卡自带零延迟硬件监听）。
- **默认策略**：软件耳返（Software Monitor）**默认关闭**，防止与声卡硬件监听叠加产生回声/相位抵消；保留一键开关供普通 USB 麦用户按需开启。

## 3. 主界面布局（一体化工作台）
从上到下分为三大功能区 + 顶部状态栏：
1. **顶部工具栏**：口琴类型切换（十孔 / 半音阶 / 复音）与调性选择（C/G/A/F 等）、麦克风设备选择、输入电平表（VU + 削波红灯）、软件耳返开关、录音延迟补偿。
2. **上方区（伴奏与波形）**：伴奏导入（拖拽或选文件）、交互式波形图、AB 段循环标记、移调滑块（`-12 ~ +12` 半音）、变速滑块（`0.5x ~ 1.5x`）。
3. **中间区（口琴可视化舞台）**：十孔 / 12·16 孔半音阶 / 24 孔复音虚拟琴格，预留实时吹/吸/压音孔位高亮与音分偏差条。
4. **下方区（录音控制台与音色预设）**：大号录音/暂停/试听按钮、4 套一键音色预设（干声无损 / 清亮独奏 / 温暖半音阶 / 芝加哥布鲁斯）、干湿比与伴奏平衡推子、一键导出 WAV/MP3。
