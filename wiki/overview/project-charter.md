# 项目章程 (Project Charter)

## 1. 产品定位

**HarpStudio（口琴录音工坊）** 是一款面向口琴玩家的**专属练琴、伴奏移调与翻奏录音工作站**（首发 Windows 桌面端，架构原生兼容 **macOS / Linux**，并预留向 **Android / iOS / 鸿蒙** 迁移的能力）。
它不是大而全的通用 DAW，而是把“导入伴奏 → 升降调练琴 → 一键美化录音 → 压音校准 → 导出成品”压缩在一个极简、直观的工作流中。

## 2. 目标用户画像

1. **进阶自学者 / 练琴党**：手里只有少数几把常用调性口琴（如 C 调十孔），需要伴奏移调、慢放扒谱、AB 循环以及实时压音音准反馈。
2. **翻奏录制者 / 短视频博主**：需要快速录出不爆音、有质感（清亮/温暖/布鲁斯失真）的口琴翻奏音频，并方便导入剪辑软件或直接导出成品。
3. **USB 麦克风 / 入门声卡用户**（如普通免驱 USB 麦或 Yamaha AG06mk2 等桌面声卡用户）：希望插上就能用，不需要自己折腾几十个 VST 插件。

## 3. 核心价值主张

- **开箱即用的口琴声学保护**：默认挂载高通滤波（去喷麦/低频嗡嗡声）+ 压限器（防爆音）+ 智能降噪。
- **口琴调性友好**：伴奏支持按半音升降调（-12 ~ +12）和变速（0.5x ~ 1.5x），互不干扰。
- **干湿双轨思维**：监听和预览听“湿声”（带混响/过载），导出时可自由调节干湿比或单独导出干声备用。

## 4. 非目标边界（Out of Scope for MVP）

- 不做多轨 MIDI 编曲、虚拟乐器宿主（VSTi）。
- 不做复杂的多人分轨混音台或视频实时录制（初期专注纯音频 + 极简频谱/封面导出）。
- 不在 MVP 阶段强依赖重型 C++/Rust 编译环境，优先保证可快速迭代交付。
