# 开发路线图 (Roadmap)

## M0：项目规划与 LLM-Wiki 建立（已完成 ✅）
- [x] 本机环境与可行性评估
- [x] 建立 `AGENTS.md` 与 `raw/` + `wiki/` 知识库
- [x] 确定 MVP 技术栈（[ADR-001](../decisions/adr-001-tech-stack.md)）与核心架构

## M1：工程初始化与核心录音/伴奏 MVP（已完成 ✅）
- [x] 初始化 Electron + Vite + React + TypeScript 项目骨架，并落地 `core / adapters / electron` 跨平台解耦目录（[ADR-002](../decisions/adr-002-cross-platform-decoupling.md)）
- [x] 音频设备管理：枚举 Windows 麦克风输入与扬声器输出，支持输入电平表（VU Meter + 削波告警）
- [x] 伴奏播放器模块：导入 MP3/WAV/FLAC，波形渲染，AB 段循环，变速与升降调调节
- [x] 基础录音引擎：干声采集与“独奏/伴奏同步录音”

## M2：口琴专属 DSP 与压音可视化（核心功能已就绪，待实机调优 🔧）
- [x] 实时 DSP 效果链：高通滤波 + 3段EQ + 压缩器 + 电子管过载 + 混响 + 防爆音限制器
- [x] 4 套一键预设：`干声无损`、`清亮独奏`、`温暖半音阶`、`芝加哥布鲁斯`
- [x] 实时音高与压音检测（YIN 算法）：支持十孔布鲁斯 / 半音阶 / 复音口琴，实时高亮孔位与音分偏差（Cents）
- [x] 混音与导出：支持伴奏与口琴音量平衡、离线渲染导出 WAV 与 320kbps MP3（待补充独立变速不变调优化）

## M3：体验打磨与原生扩展
- [x] 录音延迟一键自动校准向导（通过环回脉冲测试测量真实往返延迟，支持手动微调与单轨偏移补偿）
- [x] 工程存档（`.harpproj`）：保存伴奏音频、移调/AB循环参数、多轨音频与自定义预设状态，支持随时重新打开继续编辑
- [ ] （可选扩展）通过 Node N-API 引入 Rust `cpal` 原生音频后端，支持 WASAPI Exclusive / ASIO 超低延迟耳返
