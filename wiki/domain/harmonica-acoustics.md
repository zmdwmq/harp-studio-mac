# 口琴声学特性与录音痛点

## 1. 乐器分类与频谱特征

1. **十孔布鲁斯口琴（Diatonic Harmonica）**
   - 音域跨度约 3 个八度（C 调从 C4 到 C7）。
   - **声学特点**：近距离吹奏声压极高，中高频（2kHz–5kHz）能量集中，高音孔（7–10 孔）容易产生尖锐刺耳的泛音；低音孔（1–3 孔）吸气和压音时气息声重、低频瞬态强。
2. **半音阶口琴（Chromatic Harmonica）**
   - 音域更宽（常见 12 孔 3 个八度、16 孔 4 个八度，从 C3 到 D7）。
   - **声学特点**：带有按键推杆（Slide），音色更圆润但动态范围极大，弱奏如耳语、强奏如铜管，极易在普通录音软件中出现“弱音听不清、强音爆红”的问题。
3. **复音口琴（Tremolo Harmonica）**
   - 国内最普及的口琴类型（以 24 孔最常见，另有 21 孔、28 孔等），每个音由上下两片略微调偏（几音分）的簧片同时发声。
   - **声学特点**：天然带有柔和的拍频震音（Tremolo/Chorus 感），常见新式/老式（布鲁斯/花式）吹法与伴奏和弦。**录音忌讳**：过度过载失真会破坏双簧片的清甜震音；此外双簧片微音差会导致普通调音器读数轻微抖动，音高检测需做帧间平滑。

## 2. 录音常见问题与软件对策

| 常见痛点 | 声学原因 | HarpStudio 对策 |
| :--- | :--- | :--- |
| **喷麦 / 低频嗡嗡声** | 口鼻气流直冲麦头、手持摩擦 | 默认开启 80Hz–100Hz 高通滤波器 |
| **突然爆音削波** | 强吹和弦或高音突刺 | 链末强制挂载 Brickwall Limiter（-0.5dB） |
| **吸气/压音音量塌陷** | 吸气共鸣腔变化导致声压低于吹气 | 针对性的 3.5:1 软拐点压缩器平衡动态 |
| **高频刺耳（牙疼感）** | 3kHz–6kHz 金属簧片共振峰 | 预设 EQ 在 3.5kHz–4.5kHz 做轻微动态衰减 |
| **布鲁斯味道出不来** | 干声太单薄、缺少电子管饱和 | 内置非对称软削波过载 + 中频隆起 + 弹簧混响 |
