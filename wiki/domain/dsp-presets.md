# 口琴专属 DSP 预设参数设计

为降低新手门槛，软件内置 4 套开箱即用的声学预设（参数可在高级面板微调）：

## 1. `干声无损 (Pure Dry)`
- **适用场景**：练琴校准、录干声素材送入其他 DAW 后期。
- **效果链**：仅保留可选的 60Hz 超低频防喷高通 + -0.3dBFS 安全限幅器，不做音色染色。

## 2. `清亮独奏 (Bright Folk / Tremolo)`
- **适用场景**：流行歌曲翻奏、民谣十孔独奏、**24 孔复音口琴**独奏。
- **参数基线**：
  - 高通：85Hz
  - EQ：250Hz 轻微衰减 -2dB（去浑浊），4kHz 轻微衰减 -1.5dB（去刺耳），8kHz 空气感提升 +2dB（保留复音双簧片清甜泛音）
  - 压缩：Threshold -18dB, Ratio 3:1, Attack 10ms, Release 120ms
  - 混响：Hall 空间感，Wet 18%，Decay 1.4s

## 3. `温暖半音阶 (Warm Chromatic)`
- **适用场景**：半音阶口琴抒情曲、爵士、古典。
- **参数基线**：
  - 高通：75Hz
  - EQ：400Hz 温暖度 +1.5dB，6kHz 以上平滑滚降 -2dB（模拟丝带麦质感）
  - 压缩：Threshold -20dB, Ratio 3.5:1（保护大动态弱奏细节）
  - 混响：Warm Plate，Wet 24%，Decay 1.8s

## 4. `芝加哥布鲁斯 (Chicago Blues Tube)`
- **适用场景**：模拟“子弹头麦克风 + 电子管吉他音箱”的粗粝过载音色。
- **参数基线**：
  - 高通：120Hz，低通：4.5kHz（收窄频宽，模拟复古动圈麦与吉他喇叭频响）
  - 中频峰：800Hz–1.2kHz 提升 +5dB
  - 过载：非对称电子管软削波（Soft-clipping WaveShaper）
  - 效果：短延迟 Slapback Delay（95ms, 反馈 15%）+ 少量弹簧混响
