# 伴奏处理、双轨录制与导出数据流

## 1. 伴奏移调与变速流

```text
[本地伴奏文件 (MP3/WAV/FLAC)]
        │
        ▼ decodeAudioData
[PCM AudioBuffer] ──► [波形缩略图生成] ──► Canvas/SVG 波形展示 + AB 循环选区
        │
        ▼ (播放时实时送入 SoundTouch / Rubberband)
  - Pitch Shift: -12 ~ +12 半音（支持 0.5 半音微调以对齐老式伴奏）
  - Tempo Rate:  0.50x ~ 1.50x（变速不变调）
        │
        ▼
[伴奏音量推子] ──► 混音总线 (Master Out)
```

## 2. 干湿双轨同步录制

- **为什么录干声？**：如果直接把混响和过载录死，后期发现混响太大或过载太冲就无法挽救。
- **实现方案**：
  - 录音开始时，通过 `AudioWorklet` 将原始麦克风 PCM（仅经过可选的 80Hz 高通与防爆音保护，或完全原始）持续写入内存环形缓冲并分块落盘为临时 `dry.wav`。
  - 同时记录**伴奏起播时间戳**与**用户输入偏移补偿（Latency Offset）**。
  - 回放试听时，用 `OfflineAudioContext` 或实时 DSP 链对干声实时渲染预设效果，用户可随时切换“清亮独奏 ↔ 布鲁斯电子管”而无需重录！

## 3. 成品混音导出流

1. 使用 `OfflineAudioContext` 将 `[伴奏轨（含移调/变速）]` 与 `[口琴干声轨 + 选定 DSP 预设]` 以非实时高速渲染混音。
2. 经过总母带限制器（防止伴奏+口琴叠加后超过 0 dBFS 削波）。
3. 导出为 **16-bit/24-bit WAV** 或 **320kbps MP3**。
